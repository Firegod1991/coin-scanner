# Contributing to Coin Scanner

Thanks for trying Coin Scanner. The project runs locally because the backend needs direct access to a USB camera.

## Try it

1. Install Python 3.11 or newer.
2. Install the packages in `requirements.txt`.
3. Run `run.bat` on Windows.
4. Open `http://127.0.0.1:8765` if the desktop window does not open.

Please include your camera model, Windows version, and the camera error shown in the app when reporting a problem. Do not commit `calibration.json`, `.venv`, generated price caches, or private camera images.

Pull requests are welcome for camera support, OCR accuracy, coin catalogs, and UI improvements.
